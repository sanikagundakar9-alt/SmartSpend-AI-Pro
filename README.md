# 🚀 Smart Spend AI Pro
**An Intelligent Personal Finance Dashboard with Voice Recognition & AI Insights**

Smart Spend AI Pro ha ek advanced web-based expense tracker aahe. Ha project CSE-AIML student chya perspective ne banvla gela aahe, jyat **Data Visualization**, **Voice-to-Text Integration**, aani **Rule-based AI Insights** cha vapr kela aahe.

---

## 🌟 Key Features

* **📊 Real-time Data Visualization:** `Chart.js` vaprun tumchya kharchaacha dynamic Pie Chart tayar hoto.
* **🎤 Voice-Enabled Entry:** Web Speech API cha vapr karun user bolun (e.g., "Add 500 for Food") entries add karu shakto.
* **🧠 Smart AI Insights:** Ek logic-based engine jo tumchya spending patterns cha analysis karto aani budget alerts deto.
* **🌙 Adaptive Dark Mode:** User preference anusar modern Dark aani Light mode toggle karnyachi suvidha.
* **💾 Persistent Storage:** `LocalStorage` cha vapr kelyamule browser band kela tari data delete hot nahi.

## 🚀 Installation & Usage

1.  **Repository Clone Kara:**
    ```bash
    git clone [https://github.com/sanikagundakar9-alt/SmartSpend-AI-Pro.git](https://github.com/sanikagundakar9-alt/SmartSpend-AI-Pro.git)
    ```
2.  **Project Folder madhe ja:**
    ```bash
    cd SmartSpend-AI-Pro
    ```
3.  **Run Kara:**
    Tumchi `index.html` file kontya hi browser madhe (Chrome recommended for Voice) open kara.

## 🧠 AIML Perspective (The Logic)

Hya project madhe khaliil logic vaprun "Intelligence" add kela aahe:
1.  **Threshold-based Anomaly Detection:** Jar ekhadi single entry total budget chya 30% peksha jast asel, tar AI warning trigger hote.
2.  **Pattern Recognition:** Categorical spending pattern analysis karnya saathi JavaScript logic vaprele aahe.
